## 🎯 Kaise Khelna Hai? (2 Min Me Pro Ban Jao)

### 💻 Laptop Wale Ameer Log:
- **⬅️ ➡️ Arrow Keys** = Doraemon ko nachao
- **Space / ⬆️** = Hawa me udao usko

### 📱 Phone Wale Sher Log (Jaise Main):
- **⬅️ Button** = Left jao
- **➡️ Button** = Right jao  
- **⬆️ Button** = Jump maaro aur bolo "YAHOOO"

### 🏆 Jeetne Ka Tarika:
1. Sare **💰 coins** utha lo
2. **🐭 Mouse** pe jump karke usko harao  
3. **❤️ Lives** bachao warna Game Over 😭
4. **⭐ Score** badhao aur doston ko jalao 🔥
